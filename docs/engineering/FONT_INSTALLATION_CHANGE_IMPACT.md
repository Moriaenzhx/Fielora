# Current-user fonts and collection layouts — 2026-10-02

User flow: tidy Library/Scheduled pages; choose a genuinely installed font; import local fonts or ask the Agent to obtain/install a font for the current OS user. The user explicitly chose system-user installation, available to other applications.

Reuse Model + Harness + Capability. A shared Rust platform service parses bounded TTF/OTF/TTC bytes, enumerates system families, publishes a content-addressed font into the OS user-font directory without replacing existing files, registers it natively, and rechecks the installed bytes. Desktop import accepts paths only from the native file dialog. Agent `fonts.prepare` accepts a contained project file or public HTTPS font through existing network protections and stores immutable checkpoint bytes. `fonts.install` consumes a successful same-Run preparation receipt; Policy requires confirmation for this system mutation even under FullControl, as with other non-isolated installers. Model arguments cannot choose the destination, supply a trusted receipt, or authorize themselves. `fonts.list` is read-only. No scripts, archives, admin install, global PATH changes, schema/migration, new state/evidence/permission runtime. Installation is a Process effect, not a Project edit; its scope-specific receipt cannot verify unrelated workspace changes. Interrupted publication requires existing manual reconciliation.

Font menus use real file metadata, preserve legacy choices with explicit unavailable status, allow installed families, and retain safe CSS fallback. Registration can require other already-running software to refresh its font list/restart. Parsing is format validation, not a font license or publisher trust claim.

Validation: malformed/oversized input, no overwrite/symlink escape, digest integrity, policy and same-Run receipt rejection; preference normalization; desktop import/select/persist, native font registration and layout at wide/narrow sizes; fresh packaged smoke. Use isolated fixture directories for automated writes; verify a uniquely named temporary test font in the real user font directory and remove only that exact test file after verification. Real model source selection and Windows native registration must be reported separately from fixture/macOS checks.
