# 失败复盘与继续任务设置 Change Impact

## 2026-10-06 本次优化范围（实施前）

用户流程：真实长任务在服务初始化、测试失败和上下文压缩后继续推进，只重验受影响的验收项。桌面验证使用隔离项目、真实托管进程和确定性模型，通过开发及打包宿主证明状态/纠错/版本失效/重启连续性；真实模型原任务另验。

沿现有实现改四处：托管启动有界等待并区分STARTING、LISTENING、退出及持续不可达，重复start返回原状态而不新建；复盘附带不可由模型改写的服务合同/回执，并允许明确撤回旧假设；work_plan增补可选逐项检查结果（引用既有验收回执、记录输入hash，变动或不能核对时标待验），不授予完成或执行权限；连续命令无有效验收推进时触发有界复盘，不再只靠exit非零。仍保留正常用户授权、命令清理和独立完成裁决。

不增加Agent、数据库表、模式或永久面板。新增字段兼容旧ToolCall/Checkpoint；原计划仍可省略。模型自然语言解释不被宣称为自动语义证明；输入范围和测试覆盖仍需模型/人工审阅。测试方法要求使用隔离数据和可失败断言，通过直接测试入口获得原VerificationReceipt，打印PASS不能填为验收通过。仅更新产品与隔离测试，不操作生产业务项目/数据库/运行状态。保留旧事实和失败判断，最终验证与未覆盖范围记入AE-029。

2026-10-06；AE-029 续跑复发。用户流程：失败后继续同一项目任务时，利用已经发现的错误改进方法，保留原数据，完成实际验证。

生产 Run 的第二次继续又调用模型 254 次、压缩 26 次、生成 127 次重新规划提示后耗尽 60 分钟。原机制保留工具回执和最近模型叙述，但没有独立保留具体纠错；不同错误测试命令可绕过同命令重试检测。推理快照为 PROVIDER_DEFAULT/4096，不足以证明模型未思考；旧任务一直固定首次快照，修改设置不能作用于继续。

沿现有主模型循环增加有界 review 回合：失败后恢复或一批新的连续失败/重复观察触发；只允许返回简短的证据引用、错误假设、修正与下一项区分性检查，不执行副作用。每批动作至多一次，无新动作不反复复盘。初版无效复盘仅记录INVALID_REVIEW并回到正常纠错，不产生新的审批或无限重试；具体拒绝反馈缺口在下述续报中修正。记录进入现有 Checkpoint 账本，压缩/重启后恢复；内容始终是未验证的模型判断，不能赋予权限、修改用户目标或替代验收。未知执行结果仍先走原对账，原安全策略不变。

明确 USER_RESUME 后重新读取用户保存的同模型推理设置；单次执行段仍固定，审批继续/工具激活不改设置。保持模型和 endpoint 身份校验，不自动改用户配置、扩大输出额度或发送真实 Provider 探针。设置文案同步说明生效时间。

无 Schema/Migration/凭据变更，无第二 Runtime 或长期全局记忆；复盘最多保留六条有界记录，不持久化私有思维链或原始输出。通用提示要求先核对接口与测试前提、使用隔离测试数据，不能通过删除业务数据库或修改预期制造通过。原业务项目和生产 Run 不操作。

验证：复盘触发限频、跨重启保留、伪造回执/混入执行动作被拒绝、无验证权限；继续设置的正常/审批/endpoint 边界；真实 Core/Electron 的隔离确定性场景。真实模型是否更快、更准确完成原任务必须单独验收，不从机制测试推断。

## 2026-10-06 运行中反馈修正

实际续跑seq5656–6852在842步再次耗尽60分钟；153次Core模型请求的摘要均精确匹配已有复盘，139次普通调用也携带它。14次复盘只有2次接受，12次拒绝无具体原因；第二次接受记录只引用上一执行段的旧回执，未要求它对当前302、实际编辑字段等新证据负责。可证明的问题是纠错新鲜度和拒绝反馈缺口，不是完全没传历史。完整语义归因仍属于模型质量，不能靠门槛测试宣称已解决。

沿同一Reviews/主循环修正：每条新教训至少引用上次复盘后最近一批真实结束的工具，保留旧记录作历史但不接受只抄旧证据的新复盘；结构、字段长度、来源和陈旧引用分别反馈稳定拒绝原因。提供一次有界格式纠正回合，仍拒绝夹带执行。正常General回合也暴露原record_work_review输出工具，模型发现反证即可记录，不需等用户继续；该内部工具独立于实际Capability分发，不改变权限、已批准动作、验证或未知执行对账。

强制复盘输入保留当前请求/用户回答边界、图像与来源，以及有界最新工具事实、观察和已有教训，避免重复注入整段执行历史。普通回合的复盘反馈同时带上新近结果，注明历史判断可能已失效；不把成功退出码提升为业务通过，不持久化原始输出或私有推理。Checkpoint字段增补兼容旧记录，无迁移、第二Runtime或全局学习库。无效复盘和即时记录不重置预算，不无限重试；权限/未知结果/取消分支保持优先。

验证涵盖运行中主动纠正、旧证据复盘拒绝、新反证撤回旧判断、无效格式具体反馈与一次修复上限、压缩/重启后的反馈、混合动作零执行。Cross及真实桌面/打包专项按最终交付记录；本次不自动继续用户Run，不触碰业务项目或受限模型。语义正确率与原任务仍需独立验收。
