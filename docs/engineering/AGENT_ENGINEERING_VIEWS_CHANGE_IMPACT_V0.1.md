# Agent 工程视图与能力事实 — Change Impact（2026-09-24）

> 后续更正（2026-09-24）：本记录中的三平面正式架构定位已撤回，当前统一使用 Model + Harness + Tools，九层仅用于诊断。已实现功能、IDR 退出与当时测试/构建证据保持；不将此次文档更正写成历史包的新验收。当前规范见 docs/architecture/AGENT_ENGINEERING_VIEWS_V0.1.md。

授权：用户接受 Model + Harness + Tools 责任基线、三平面与共享基础设施工程视图、九层诊断视图，要求补充缺少能力；随后要求先去除尚无实际收益证明的 IDR。

当前流程：用户询问/要求使用某能力 → Agent 查本轮真实目录及具体定义 → 区分注册、后端状态、权限和实测结果 → 经同一 Harness 执行及验证。补充目录分页和精确详情，防止部分目录或不可用后端被解释为全局能力缺失。复用现有 ToolSpec、ToolProvider、PolicyEngine 和回执，不增加 Registry 服务、数据库、权限枚举或第二执行通道。

IDR 从生产默认运行链路退出：不读取 Human Model、不产生个性化投影、不向模型暴露学习控制工具。保留历史 schema、迁移、数据与隔离历史测试，不清空用户库。重新启用不是插件、模型或旧 Run 可以自行做的决定。通用 Agent Profile 与当前用户约束仍保留。历史 IDR 工程验证不证明真实收益，也不因退出而改写历史结果。

能力目录是只读投影，不进行网络健康探测、凭据解析或预授权。具体调用仍在执行前按实际参数、当前请求范围与授权重新检查。新增可选查询参数兼容空参数；分页绑定目录摘要，改变目录后必须从第一页重新查，缺项表示当前目录未暴露而非产品永久不支持。来源 metadata 属数据，不构成权限。

验证：注册与可达性分离、不可用 provider、被过滤的工具、精确详情、分页与目录变化、伪造/非法查询；已有非空 Human Model 时生产退出与正常上下文/重启；开发及独立包 Skill 安装/状态查询回归。真实模型选择工具仍需单独验收，不以替身代替。新物理服务、完整桌面 Computer Use、通用 Resource/Blueprint 平台不凭架构图宣称已实现。
