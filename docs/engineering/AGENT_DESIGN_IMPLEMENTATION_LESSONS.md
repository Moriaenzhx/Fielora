# Agent 故障记录维护约定

个人经验记录与面试素材仅保存在本地，不随 GitHub 源码、Release 附件或 App 分发。
本机完整记录位于 `docs/local/AGENT_DESIGN_IMPLEMENTATION_LESSONS.md`，沿用已有 AE 编号和证据链接；`docs/local/` 已加入 Git 忽略规则。

## 维护方式

- 本机开展相关调查或修复时，按需查阅本地索引并更新同一条因果链，不提交个人记录。
- 新克隆没有本地记录是正常情况，不作为开发、构建或验证的前置条件；依据公开规范、代码和测试继续工作。
- 公开仓库保留产品维护必需的原因、机制、测试和未验证范围，分别写入对应工程文档、项目事实和决策；个人讲述稿、追问素材及选材索引留在本地。
- 区分已确认原因与推测、动作完成与结果验证、工程测试与真实模型任务验收。新证据推翻旧判断时保留更正依据。
- 历史文档中的 AE 编号是本地经验记录编号，本文件不再提供案例正文。不得为补全公开链接而重新上传本地记录。

本次调整作用于当前源码及今后提交；已公开的旧提交和标签不会因普通删除自动消失。
