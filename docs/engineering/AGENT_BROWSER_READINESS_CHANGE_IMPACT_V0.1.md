# 浏览器未就绪诊断与恢复 Change Impact（2026-09-24）

用户流程：继续已有 Skill 安装任务时，浏览器获取缺失资源；页面或宿主未就绪时返回真实原因与可执行恢复方向，不把它解释为整个网站不可达。沿用用户已授权的 Agent 故障修复范围。

- 已确认：原 Run 第 45–60 步执行了 verify_skill 并报告 12 个缺失路径，随后两次 browser.open 返回 BROWSER_PAGE_NOT_READY。该错误同时覆盖加载、宿主显示、活动页切换，历史回执没有记录是哪一条件；因此不能追认历史网络根因。模型未按反馈 inspect，误用本地 read_file(URL)，然后索要已有的来源。
- 修改范围：现有 BrowserRuntime 的有界就绪等待、类型化错误事实和只读观察恢复；既有 Host/Renderer 显示交接如复现证实存在缺陷则修复；工作检查点保留诊断字段。仅针对真实执行事实，不新增语义分类器或强制安装工作流。
- 不变量：保留 Run/page/navigation 归属、隔离页面、协议/凭据边界、输入新鲜度、未知输入不重放、取消和超时。宿主显示与网络状态分离，未就绪不能产生 Verification PASS。不新增任意抓取、下载解包、脚本执行权限、Schema、第二 Runtime 或生产数据改写。
- 验证：隔离 Electron 中复现隐藏面板/未完成加载/页面失效/导航失败，恢复后获得真实页面；覆盖 Host 回执及上下文保真、既有浏览器交互检查。公开 GitHub 观察如执行，仅证明本次可达性，不代替历史根因或真实模型完成安装。
- 回滚：撤回源码与相应文档即可；既有 additive 诊断字段旧记录可缺省。真实 Qwen、完整 Archify 和原任务验收独立报告。

复现后的实施细化：open/inspect/reload 对当前 Run 的已提交文档作只读观察，不以原生面板可见作为读文本前提；回执明确 interaction_ready=false，输入/截图/验收继续要求可见有效表面。错误分开记录页面归属、文档加载、导航失败及表面状态，导航等待可取消且有界。只读 inspect 请求展示本 Run 面板。另修复长页面文字静默截断：披露字符范围/partial，不允许在遗漏文字上通过 absent 断言；并明确这不是完整源文件下载能力。未新增网络接口或跳过页面身份/权限。
