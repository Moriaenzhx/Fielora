# Agent 工具发现与受控安装 — Change Impact（2026-09-25）

当前流程：用户要求使用 Skill 完成工作，系统默认 Node 不兼容；Model 应先发现已有程序并以绝对路径使用，缺失时可准备和安装必要工具。沿 Model + Harness + Capability、既有 ToolSpec / PolicyEngine / Approval / ToolCall / checkpoint 实现，不增加第二套权限、注册表或状态机。

授权边界：用户已确认可信来源、实际下载 <=20 MiB、仅项目隔离目录、不改系统/PATH、不运行安装脚本可免安装确认。其他安装必须人工确认，包括 FullControl。ReadOnly 仍遵守请求审批预设。Model 选择方案，不能提交风险等级或可信来源结论作为授权。准备只做受控 HTTPS 下载及隔离缓存；发布使用同 Run 成功准备回执，审批绑定具体来源、版本、摘要、大小、目标及影响。未知来源默认需确认。包管理器安装命令要求确认，不自动执行远程脚本。

首批：环境发现扫描 PATH 的全部候选及有限标准运行时目录，不执行发现的程序；版本检查走已有 run_command。可控便携 ZIP 支持官方 Node、ripgrep 及需确认的公开 HTTPS ZIP；只发布到 .fielora/tools/<name>/<digest>，无覆盖、无全局安装、无安装脚本、无 PATH 修改。严格限制压缩和展开大小，拒绝链接、穿越、设备名和冲突路径；取消/错误不发布半成品。未支持格式返回明确限制。

同时修正本次暴露的 Artifact 外层类型反馈、失败变参虚假进展与压缩冗余；不改生产 Run 或覆盖用户失败输入。回滚是撤回新工具准入与新增代码；已安装隔离目录保留。无 Schema/Migration、credential 或供应商绑定变更。

验证：低风险/超限/非可信/跨 Run/伪造回执/审批拒绝；恶意 ZIP、取消、哈希改变、路径链接；PATH 中旧版优先但新版可发现；真实 Archify 在绝对路径兼容 Node 下运行。替身和维护调用不等于真实模型已自主恢复。桌面审批以具体安装摘要可审阅为标准。
