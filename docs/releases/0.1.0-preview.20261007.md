# Fielora 0.1.0-preview.20261007

macOS Apple Silicon 开发预览版，源码来自 `phase/complete-agent-v0.1`。

[下载与完整附件](https://github.com/Moriaenzhx/Fielora/releases/tag/v0.1.0-preview.20261007)

## 安装

1. 下载 `Fielora-0.1.0-preview.20261007-macos-arm64.dmg`，打开后将 `Fielora.app` 拖入 `Applications`。也提供包含同一 App 的 ZIP。
2. 退出旧版 Fielora，再从“应用程序”打开新版。
3. 在“设置 → 模型配置”添加自己的服务、模型和 API Key，再打开本地项目开始对话。安装包不包含账户、API Key、项目或会话数据。

App 自带 Electron 和 Rust Core；启动不要求安装 Rust、Node.js 或 Python。Agent 执行具体项目时使用的 Git、Python、Node.js 等外部工具需要在本机可用。

这是 **ARM64 包，仅面向 Apple Silicon（M 系列）Mac**，未提供 Intel 或 Universal 包。包声明最低 macOS 12.0，本轮实际测试系统是 macOS 26.6.2；最低系统版本尚未实机验收。

## macOS 首次打开

本包没有 Apple Developer ID 签名和 Apple 公证；本地 ad-hoc 签名只校验包完整性，不认证开发者身份。macOS 可能阻止首次打开。确认来自本仓库且校验和匹配后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，尝试打开后进入“系统设置 → 隐私与安全性 → 仍要打开”。受管理的 Mac 可能不允许这个例外。不要关闭系统全局安全保护。

下载 `SHA256SUMS.txt`，在下载目录验证：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

该命令校验清单中的全部附件；如果只下载 DMG，可用 `shasum -a 256 Fielora-0.1.0-preview.20261007-macos-arm64.dmg` 与清单对应行比较。

已有用户升级前请保留本机 Fielora 数据备份。本版包含本地凭据迁移，API Key 保存在设备 SQLite 数据库内，未加密；不要分享该数据库或包含凭据的备份，也不要用旧版本直接打开升级后的数据库。

## 本次更新

- 统一 Mac 外观、系统字体列表和字号缩放；支持当前用户字体导入及 Agent 安装字体。
- API Key 保存和测试连接复用本地数据库，增加发送前检查和清楚的模型推理参数说明。

- 明确项目依赖安装的审批范围与 macOS 命令隔离反馈。
- 完成后折叠执行过程，突出交付结果，缩小审阅卡片并调整阅读间距。
- 根据窗口空间显示环境与变更信息；右上角按钮保持可见，变更摘要直接进入审阅，环境按钮只打开环境菜单。

## 预览版边界

完整 PreMerge 与真实模型业务验收不等同于专项测试。发行页列出本次实际通过和未通过的检查，不能把确定性模型替身的通过结果当作真实模型质量认证。

本次提交前检查：TypeScript 295 项通过，Rust 481 项通过、5 项按原配置忽略，Core 集成 14 项通过，类型/Lint/Clippy/契约/文档和基础桌面 E2E 通过。完整 PreMerge 在 Mac 浏览器关闭页面后的 WebContents 数量断言失败，后续 Desktop Foundation 阶段未运行；没有跳过或放宽失败断言。打包后专项结果见同版本发行页。

已知 Mac 浏览器生命周期及 Desktop Foundation E2E 待处理项见 [Mac 开发指南](../engineering/MACOS_DEVELOPMENT.md)。本版不宣称完整 PreMerge 或 Windows 回归全部通过。

真实模型完成报告仍可能遗漏业务缺陷。工作室管理器独立验收此前发现客户待回款统计、同 ID 冲突持久化、无效备份恢复三类问题，尚未由本次 Fielora 发布修复。请对生成的项目单独验收，特别是涉及金额和数据恢复的操作。

问题反馈请附版本标签、系统与芯片、复现步骤和脱敏截图：[GitHub Issues](https://github.com/Moriaenzhx/Fielora/issues)。
