# 纸页 · 阅读清单

一个用来演示 Fielora 项目工作流的小项目。这里的内容均为公开展示样例。

## 想解决的问题

收藏了很多文章，却很难记住哪些读过、哪些值得再看。希望做一个简单的本地阅读清单，打开就能接着读。

## 第一版

- 添加文章标题、链接和标签。
- 按“待读 / 已读”筛选；支持标题搜索。
- 每篇文章可以保存一句阅读笔记。
- 数据保存在本机，可导出 JSON 备份。

## 设计取舍

先做好单人阅读，不做账户、推荐流或社交功能。页面应在手机和电脑上都好用，键盘可以完成主要操作。

## 验收重点

1. 刷新后保留清单和笔记。
2. 搜索与状态筛选可以同时使用。
3. 空清单、无搜索结果和无效链接都有清楚的提示。
4. 导出文件可以重新导入，内容不丢失。
