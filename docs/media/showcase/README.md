## 复现工作区画面

1. 从 Fielora 添加本仓库的 [`docs/showcase/reading-list`](../../showcase/reading-list) 文件夹。
2. 新建对话，在右侧“文件”中打开 `README.md`，选择 Markdown 预览。
3. 填写任务草稿。截图中的草稿没有发送。
4. 通过应用自身的侧栏和文件目录开关调整布局，再截取应用窗口。
