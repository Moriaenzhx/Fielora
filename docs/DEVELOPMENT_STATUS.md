# 开发进展

更新于 2026-11-06。Fielora 仍处于早期开发阶段，暂不提供公开安装包。

## 代码与版本

| 位置 | 内容 |
| --- | --- |
| `main` | 默认仓库入口，产品代码是较早的基线；更新首页不等于合并开发分支。 |
| [`phase/complete-agent-v0.1`](https://github.com/Moriaenzhx/Fielora/tree/phase/complete-agent-v0.1) | 当前公开开发分支，包含项目对话、多模型、编码与审阅、浏览器、工具扩展和 macOS 适配。 |
| 0.2.0 本机资料库 | 本地已实现并保留打包验证截图；该功能提交尚未推送到公开开发分支。首页作为开发预览展示。 |
| 语音与手机控制 | 本地实验中，尚未作为稳定功能发布。 |

目前公开开发分支的核对基线为 [`b5ac134`](https://github.com/Moriaenzhx/Fielora/commit/b5ac134b5fe934f1ba0c97682b9ed8dbbf358d06)。本文不把未推送的本地代码写成已公开发行。

## 平台

- **macOS Apple Silicon**：日常本机开发与小范围测试。窗口截图需要 macOS 14+ 和系统权限。
- **Windows 11 x64**：已有桌面实现及历史验证，近期新增能力需要逐项回归。
- **Linux / Intel Mac**：暂不承诺支持。

## 当前重点

1. 让真实任务更稳定地完成，减少重复尝试，明确实际结果。
2. 改善长任务的上下文、暂停、继续与中断恢复。
3. 完善文件、差异、网页预览和资料库之间的工作流程。
4. 完成平台回归与安装体验后，再开放安装包。

截图与测试记录只能证明对应版本、对应任务的行为，不能替代全部场景验收。详细实现说明见[文档导航](README.md)，图片来源见[截图说明](media/showcase/README.md)。
