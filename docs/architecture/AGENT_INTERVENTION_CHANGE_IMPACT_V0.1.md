# Agent intervention — Change Impact V0.1

状态：2026-10-22 工程与 macOS 开发/打包宿主验证通过；真实模型及原任务另行验收。非新 Freeze/Gate。

**用户流程：** 当前任务运行时，用户可以停止它、保留/删除尚未执行的追加消息，或明确将一条消息用于纠正当前任务。纠正必须进入同一个 Run；排队消息不能伪装成已经生效的纠正。Stop 后不自动启动下一条消息。

**当前原因：** UI 的 Stop 与发送共享忙碌锁；队列在任何终态后都会自动启动；“调整方向”当前仅编辑草稿。此前原生真实任务中的 Stop 点击失败具体原因仍未完全追证，这些确定的代码缺口不代替对那次操作的事实判断。

**实现边界：** 沿既有 Run、Conversation message、Checkpoint/event ledger、pause/resume、取消与恢复机制实现。Stop 独立于发送锁，等待实际执行状态收敛；队列暂停状态只属于已有 UI 排队数据。纠正在安全执行边界接入：已开始动作先得到实际回执，未执行的旧动作不能绕过新指令继续；输入准入、原始请求和新指令保留来源。最新消息不是工具执行许可或验证证据。不得自动重放 UNKNOWN 原生输入或命令，不因纠正自动扩展权限或重置资源预算。

**兼容与安全：** 不新增 Schema/Migration、第二 Runtime/State/Permission/Evidence 所有者；旧 Run 和队列仍可读取。新增用户纠正入口只接受可信用户提交的同 Conversation 消息，校验 Run 身份、生命周期与重试幂等性；模型、网页和 Connector 不能代为提交。终态竞态必须明确表示尚未应用，不能回报虚假的成功。停止/删除不抹去已发生的副作用或历史。

**验证：** 真实 Electron + Core + 确定模型测试覆盖取消后队列不启动、消息保留/删除、切对话和重启、显式继续队列、同 Run 纠正到实际新目标、旧批准失效、终态竞态、未知执行恢复边界与无重复执行。静态/单测/FIPC/PreMerge 与 packaged smoke 分别记录；真实模型代表任务及同模型对照在第三项执行，不能由替身 PASS 代替。

**回滚：** 可回退本轮代码；新事件 payload 类型和 UI 排队附加字段必须能被旧读取路径忽略，原始消息和既有账本保持完整。
